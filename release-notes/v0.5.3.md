## อัปเดตในชุดนี้

- แก้เส้นทางเปิด Mic DDUI ที่กระตุ้นให้เซิร์ฟเวอร์ค้างเมื่อเปิด–ปิดรัว ๆ: กันคำขอซ้ำก่อนส่งงานไป tick ถัดไป และไม่เก็บคำขอเปิดไว้ต่อคิว
- เอางานจัดการไอเทมและคำขอซิงก์ออกจากตอนเปิดฟอร์ม ลดการเขียน inventory และ tags ที่ไม่จำเป็น
- คูลดาวน์เปิด Mic DDUI ซ้ำหลังปิด 5 วินาที และคูลดาวน์หลังเปลี่ยนระยะ 5 วินาที
- แก้ Slider ให้ส่งค่าล่าสุดครั้งเดียวหลังหยุดเลื่อนประมาณ 0.75 วินาที
- เมื่อเซิร์ฟเวอร์ยืนยันระยะแล้ว ปิด DDUI และแจ้ง `[ SleepyMic ] เปลี่ยนระยะเป็น … บล็อกแล้ว`
- เอาข้อความคูลดาวน์ในหน้าออก กดเปิดระหว่างคูลดาวน์จะแจ้งในแชต โดยจำกัดความถี่ข้อความ
- ลบไอเทม DDUI Test และโค้ดทดสอบออก
- รวมการลดงาน inventory/tag ของระบบไมค์ และคำสั่ง `vcb perf` สำหรับวัด CPU/wall time ของงานหลักในปลั๊กอิน MumbleHost (ไม่ใช่ CPU ทั้งเซิร์ฟเวอร์)
- เพิ่มหน้าแอปธนาคารเหนือ Settings ใน SleepyPhone แสดงเลขบัญชี/ยอดเงิน พร้อมปุ่มโอนเงินและทัชสแกน เป็นหน้าเตรียมไว้ ยังไม่มีระบบธุรกรรม

## ไฟล์แนบ

- `endstone_mumble_host-0.5.3-py3-none-any.whl` — ปลั๊กอิน Endstone พร้อม Mumble Server
- `VC_Mumble_ItemMic_v2.15.7_MicFix.mcaddon` — แอดออน Mic, SleepyPhone และไอเทมเงิน
- `VC-Mumla-v0.5-aec-debug.apk` — แอป Android VC Mumla APK เดิม ไม่มีการเปลี่ยนแอปใน release นี้
- `SHA256SUMS.txt` — checksum ของไฟล์แนบ

เจ้าของเซิร์ฟเวอร์ทดสอบชุดกันเปิดซ้ำและตัดงานตอนเปิดแล้วไม่พบอาการค้างในการทดสอบล่าสุด ส่วน Slider และการปิดฟอร์มหลังยืนยันผ่านการทดสอบโค้ดแล้ว ควรตรวจพฤติกรรมในเกมหลังอัปเดตด้วย
