    คู่มือ

    สร้าง Key ของเซิร์ฟเวอร์ที่จะติดตั้งระบบไมค์โดยเฉพาะ

    1. เข้าสู่ระบบที่ MCSV แล้วเปิดหน้าเซิร์ฟเวอร์ของคุณ
    2. ในเมนูเซิร์ฟเวอร์ เลือก ระบบ → API / MCP (เฉพาะเจ้าของเซิร์ฟเวอร์)
    3. กด สร้าง key แล้วตั้งชื่อ เช่น SleepyMumla
    4. เลือกสิทธิ์ กำหนดเอง เปิดอ่านข้อมูลเซิร์ฟเวอร์ อ่านไฟล์ และจัดการไฟล์ (เขียน/อัปโหลด/แตกไฟล์/บีบอัด) และจัดการสถานะเซิร์ฟเวอร์เพื่อ Restart อัตโนมัติ · Key แบบอ่านอย่างเดียวติดตั้งไม่ได้
    5. กดสร้าง แล้วคัดลอก Token ที่ขึ้นต้นด้วย mcsv_ ซึ่งแสดงครั้งเดียวก่อนปิดหน้าต่าง
    6. กลับมาหน้านี้ วาง Key แล้วกด ตรวจสอบเซิร์ฟเวอร์

    เก็บ API Key เหมือนรหัสผ่าน หากหา Key เดิมไม่พบ ให้สร้าง Key ใหม่ ไม่ต้องส่ง Key ในแชต

    เปิดคู่มือ API / MCP ของ MCSV ↗

    ระบบไมค์นี้ต้องใช้ Minecraft Bedrock ที่รัน Endstone เท่านั้น

    การติดตั้งใหม่ลบไฟล์ทั้งหมด รวมถึง Backup ภายในเซิร์ฟเวอร์ ต้องดาวน์โหลด Backup เก็บลงเครื่องก่อนดำเนินการ
    1. เปิดหน้าเซิร์ฟเวอร์ใน MCSV → สำรองข้อมูล สร้าง Backup และดาวน์โหลดเก็บลงเครื่อง
    2. เปิด ตั้งค่า → ติดตั้งใหม่ แล้วเลือก เปลี่ยนประเภท
    3. เลือก Minecraft Bedrock / Endstone และเวอร์ชันที่ต้องการ ต้องเป็น Endstone ไม่ใช่ Bedrock Dedicated Server ธรรมดา
    4. ตรวจว่าดาวน์โหลด Backup แล้ว จากนั้นยืนยันการติดตั้งใหม่ใน MCSV และรอจนเสร็จ
    5. หากไม่มี Endstone ให้เลือก ให้ติดต่อผู้ดูแล MCSV ก่อน ยังไม่ต้องยืนยันการติดตั้งชนิดอื่น
    6. กลับมาหน้านี้ แล้วตรวจ API Key อีกครั้ง หาก Key เดิมใช้ไม่ได้ ให้สร้างใหม่ที่ ระบบ → API / MCP
    เปิดคู่มือตั้งค่าเซิร์ฟเวอร์ของ MCSV ↗

    ติดตั้งได้ขณะเซิร์ฟเวอร์เปิดอยู่ ระบบจะ Restart อัตโนมัติหลังติดตั้งเสร็จ ระบบสำรองแพ็กเดิมและไฟล์ตั้งค่าที่แก้ไว้ในเซิร์ฟเวอร์ · ครั้งแรกที่เปิด ปลั๊กอินจะดาวน์โหลดระบบเสียงเพิ่มเติม อาจใช้เวลาหลายนาที

    เลือกพอร์ตเพิ่มเติมที่ยังไม่ได้ใช้กับบริการอื่น ต้องเปิดทั้ง TCP และ UDP
